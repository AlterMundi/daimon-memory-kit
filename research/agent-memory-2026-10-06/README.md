# Investigation — lifelong agent memory and consolidation

Research cutoff and access date: 2026-10-06. State: `closed` — five raw reports
and their consolidations archived. Research completion does not imply completed
runtime upgrades, model evaluation or live adoption.

## Question and method

Which evidenced mechanisms should improve HMK as a being's primary durable
memory, and what would justify replacing a component or the system later?

Four research children worked in two waves; the coordinator researched the
evaluation lane and read all completed reports before consolidation. The installed
`multi-agent-research` workflow supplied the write-first, attributed archive
structure. Its attribution to Mariano has not been verified; no separate research
service was invoked. Owner instructions selected English and this project as the
authorized work/publication scope. See the [manifest](agent_reports/MANIFEST.md)
for framing, division, confidence and execution limits.

Primary papers, official documentation and selected implementation files were
opened; repository versions were pinned where inspected. The raw ledgers contain
63 source groups and the [deduplicated bibliography](BIBLIOGRAPHY.md) contains
81 canonical URLs, including date verification and code corroboration. These are
archive counts, not independent studies. Reported performance was not rerun.

## Conclusion and next work

Improve HMK's preservation, attributed native history, retrieval and reliable delta
capture; test staged consolidation and render a diary from selected episodes.
Keep episodes, current accounts and learned interpretations linked but distinct.
Prepare component comparisons and reversible export rather than selecting a
wholesale replacement from incomparable scores.

The [durable-recall plan](../../docs/durable-recall-plan.md) remains the work record.
Existing preservation defects are still unfixed. Source-loss capture/recall,
ten-year ranking perturbation, consolidation, scale and receiving acceptance
remain untested. Markdown is the delivered format; a PDF was not requested or
generated and no LaTeX/pandoc toolchain was available. Research lanes used public
sources and did not access private corpora or another being's diary, or change
runtime hooks, schedulers or deployments. A brief publication milestone was
curated separately in the authorized being pool after a verified snapshot;
persistence and configured-provider retrieval were checked. No retrieved private
content entered this public research archive.
