## Local responsibilities

Keep curated recall lightweight and point back to Daimon Field for changing project
state. Preserve lasting meaning, provenance and revisions; do not turn memory into
a duplicate board. Human-requested curation is not automatic collective ingestion.

Preserve HMK-native authored records and their history. Matrix-signed memory uses
its owning projection/correction boundary; not every HMK row is a disposable index.
Investigate portable domain operations, selected export/reconciliation and causal
conflict visibility before any distributed-storage migration. Do not merge live
SQLite database files. No persistence engine has been selected to replace SQLite.
